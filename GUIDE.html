How to run and deploy this website.

A short, non-technical walkthrough. Follow the steps top to bottom.

01 What you need first

Install these once on your computer. They are all free.

  1. Node.js — download from nodejs.org. Pick the LTS version. Install with default options.
  2. Git — download from git-scm.com. Install with defaults.
  3. A code editor if you don't have one — VS Code is fine.
Check installs worked. Open Terminal (Mac) or PowerShell (Windows) and type node -v and git --version. If both print a version number, you're good.

02 Run the website on your laptop

Get the code

git clone https://github.com/romanchal/RewardArbitrage.git
cd RewardArbitrage/app

Install dependencies

This downloads the libraries the site uses. Takes about a minute.

npm install

Start the dev server

npm run dev

Open http://localhost:5173 in your browser. That's the site running locally. Change any file — it refreshes on save.

Stop the server: press Ctrl + C in the terminal.

03 Deploy to Firebase (free)

Firebase Hosting gives you a free public URL like your-app.web.app. The site already uses Firebase for its database, so this is the easiest place to host it.

Step 1 — Sign in to Firebase

  1. Go to console.firebase.google.com and sign in with a Google account.
  2. You should already see the project clubweb-f021e. If not, ask the owner to add you.

Step 2 — Install the Firebase tool

npm install -g firebase-tools

Then log in from the terminal:

firebase login

A browser window opens. Sign in with the same Google account. Close the tab when done.

Step 3 — Build the site

This creates a production-ready folder called dist.

cd RewardArbitrage/app
npm run build

Step 4 — Deploy

firebase deploy

Wait 30–60 seconds. The terminal prints a URL — that's your live website. Share it.

Re-deploying later: after any code changes, just run npm run build then firebase deploy again.

04 View submissions in Excel

Every form submission is saved automatically. To download them as an Excel file:

  1. Open the admin page in your browser. On the live site it's:
    https://your-app.web.app/admin?key=pbcoe-ai-2026
    Locally it's:
    http://localhost:5173/admin?key=pbcoe-ai-2026
  2. You'll see two tabs: Committee and Members.
  3. Click "Export .xlsx (all)" — a file downloads with both sheets inside. Open it in Excel or Google Sheets.
  4. Use "Export .csv" if you only want the current tab.
  5. Click "Refresh" anytime to pull the latest submissions.
Keep the admin key private. Anyone with that URL can read submissions. To change the key, open app/src/pages/Admin.jsx and edit line 11 (ADMIN_KEY), then re-deploy.

05 Common issues

  • npm install fails: delete the node_modules folder and try again.
  • Admin page shows "Failed to load": Firestore security rules block reads. Open the Firebase Console → Firestore → Rules and allow reads for the members and committee collections.
  • Form says "submission failed": same reason — rules block writes. Adjust in Firebase Console.
  • Site looks broken after deploy: re-run npm run build then firebase deploy.
